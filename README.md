# MachineLearning

Interactive Machine Learning experiments and visual labs.

## Projects

- **[Interactive ML Visual Lab](interactive_ml_visual_lab/)**: Streamlit application exploring:
  1. **Factor Analysis** on the Iris dataset.
  2. **Hidden Markov Model (HMM)** forward/backward message passing.
  3. **Adaptive Basis Function Models** for nonlinear function approximation (comparing Polynomial Regression, Fixed RBF Networks, and Adaptive RBF Networks with dynamic center and width optimization).
